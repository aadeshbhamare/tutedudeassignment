# Python Assignment: Arithmetic Operations & String Concatenation

## Project Description
This project contains a single Python program that performs **two tasks**:

1. **Task 1:** Arithmetic operations on two numbers(input by user)  
2. **Task 2:** String concatenation to create a personalized greeting(input bu user)  

## Tasks Performed
### Task 1: Arithmetic Operations
- Takes two numbers as input from the user  
- Performs addition, subtraction, multiplication, and division  
- Displays the result of each operation  
### Task 2: String Concatenation
- Takes the user's first name and last name as input  
- Combines them into a full name using string concatenation  
- Prints a personalized greeting message
