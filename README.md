# tutedudeassignment
# Python Assignment: Basics & Control Structures in Python

## Project Description
This project contains **two Python assignment programs** that demonstrate the fundamentals of Python programming, including **arithmetic operations, string manipulation, conditional statements, and loops**

### Assignment 1
1. Arithmetic Operations on two user-input numbers.
2. String Concatenation to create a personalized greeting.

### Assignment 2
1. Check whether a number is Even or Odd using an if-else statement.
2. Calculate the sum of integers from 1 to 50 using a for loop.

---

## Tasks Performed

### Assignment 1

#### Task 1: Arithmetic Operations
- Takes two numbers as input from the user.
- Performs:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Displays the result of each operation.

#### Task 2: String Concatenation
- Takes the user's first name and last name as input.
- Combines them into a full name using string concatenation.
- Displays a personalized greeting message.

---

### Assignment 2

#### Task 1: Even or Odd Checker
- Takes an integer input from the user.
- Uses an **if-else** statement to determine whether the number is even or odd.
- Displays the result accordingly.

#### Task 2: Sum of Integers from 1 to 50
- Uses a **for loop** to iterate through numbers from 1 to 50.
- Calculates the sum of all integers in the given range.
- Displays the final sum.

---

## Files Included
