# Assignment 1: Arithmetic Operations & String Concatenation

## Project Description

This project contains a single Python program that performs **two tasks**:

1. **Task 1:** Arithmetic operations on two numbers (input by user)
2. **Task 2:** String concatenation to create a personalized greeting (input by user)

## Tasks Performed

### Task 1: Arithmetic Operations

* Takes two numbers as input from the user.
* Performs addition, subtraction, multiplication, and division.
* Displays the result of each operation.

### Task 2: String Concatenation

* Takes the user's first name and last name as input.
* Combines them into a full name using string concatenation.
* Prints a personalized greeting message.

## File Included

* `assignment1(tutedude).py` – Contains both Task 1 (Arithmetic Operations) and Task 2 (Personalized Greeting).

## Technology Used

* Programming Language: Python 3
* IDE: PyCharm

## How to Run the Program

1. Open the project in **PyCharm**.
2. Open the file `assignment1(tutedude).py`.
3. Click **Run**.

**OR** run using terminal:

```bash
python assignment1(tutedude).py
```

## Tasks Performed

### Task 1: Even or Odd Checker

* Displays the appropriate result.

### Task 2: Sum of Integers from 1 to 50
