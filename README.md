# Python Assignments: Basics & Control Structures

## Assignment 1: Arithmetic Operations & String Concatenation

### Project Description
This project contains a single Python program that performs **two tasks**:

1. **Task 1:** Arithmetic operations on two numbers (input by user)
2. **Task 2:** String concatenation to create a personalized greeting (input by user)

### Tasks Performed

#### Task 1: Arithmetic Operations
- Takes two numbers as input from the user.
- Performs addition, subtraction, multiplication, and division.
- Displays the result of each operation.

#### Task 2: String Concatenation
- Takes the user's first name and last name as input.
- Combines them into a full name using string concatenation.
- Prints a personalized greeting message.

### File Included
- `assignment1(tutedude).py` – Contains both Task 1 (Arithmetic Operations) and Task 2 (String Concatenation).

### Technology Used
- Programming Language: Python 3
- IDE: PyCharm

### How to Run the Program
1. Open the project in **PyCharm**
2. Open the file `assignment1(tutedude).py`
3. Click **Run**

(OR) Run using terminal:

```bash
python assignment1(tutedude).py
```

# Assignment 2: Control Structures in Python

### Project Description
This project contains a single Python program that performs **two tasks**:

1. **Task 1:** Check if a Number is Even or Odd (input by user)
2. **Task 2:** Calculate the sum of integers from 1 to 50 using a for loop

### Tasks Performed

#### Task 1: Check if a Number is Even or Odd
- Takes an integer input from the user.
- Checks whether the number is even or odd using an if-else statement.
- Displays the result accordingly.

#### Task 2: Sum of Integers from 1 to 50 Using a Loop
- Uses a for loop to iterate over numbers from 1 to 50.
- Calculates the sum of all integers in this range.
- Displays the final sum.
